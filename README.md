# ブロック崩し for Web

ブラウザだけで遊べる、Canvas と JavaScript で作ったブロック崩しです。元の DxLib 版の基本ルールをWeb向けに再構成し、通常・硬い・爆弾・1UP・高得点・バー拡大／縮小・全消去・壊せないブロックを実装しています。

## 遊び方

- マウス／指：バーを動かす
- `←` `→`：キーボードでバーを動かす
- `Space`：開始・一時停止・再開
- `R`：最初からやり直す

全16ステージを攻略してください。ハイスコアはブラウザ内に保存されます。

## 公開

静的な HTML、CSS、JavaScript だけで動作するため、GitHub Pages などの静的ホスティングで公開できます。

## 素材について

このWeb版は、Canvas で描画した独自の図形とWeb Audio APIによる効果音だけを使用しています。元のDxLib版に同梱されている画像・音声ファイルは使用していません。
