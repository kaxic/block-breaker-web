# ブロック崩し for Web

DxLib版の画面素材、16ステージのCSV配置、マウス操作をWebブラウザ向けに移植した版です。

## 操作

- タイトル画面の `GAME START` を左クリック：ゲーム開始
- マウス移動：バーを左右に移動
- 右クリック：一時停止
- 一時停止中に左クリック：再開

## 内容

- 元の `block1.csv` 〜 `block16.csv` をそのまま読み込み
- 通常・耐久・爆弾・残機追加・高得点・バー拡大／縮小・全消去・壊せないブロックを再現
- ハイスコアはブラウザ内に保存

## 素材とクレジット

DxLib版に同梱されている画像・効果音素材を使用しています。ブロック・壁・特殊ブロック・ミス・クリア時の効果音は、最初のゲーム開始クリック後に元版と同じタイミングで再生されます。元のソースではポケットサウンドおよびOtoLogicの効果音素材をクレジットしています。再配布時は各素材の利用規約を確認してください。
